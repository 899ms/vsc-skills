# VSC 路由行为验收

这些用例用于模型行为验收，不能由目录单元测试代替。对话相互独立，默认七个技能均可读。先检查选择和交付范围；涉及图片、视频或 Eagle 的案例只做路由演练，不提交生成任务或写入 Eagle。

| 输入及上下文 | 预期行为 | 需要防止的错误 |
| --- | --- | --- |
| 新对话仅输入 `$vsc` | 简短能力导航，询问创作目标 | 随机生成、列出冗长英文技能清单 |
| `$vsc 有哪些能力？` | 展示可用能力与输入示例 | 直接开始创作 |
| `$vsc 给陶瓷猫香水瓶探索 8 种稀有视觉风格，只要提示词` | rare-style-explorer；8 组提示词 | 调用生图、只推荐不执行 |
| `$vsc 九尾狐衔灯走过雪夜竹林，东方神怪工笔水墨，写一组提示词` | shan-ze-school；提示词 | 因“风格”二字转入随机风格探索 |
| `$vsc 5 组韩系生活写真提示词，荷塘、BM 风、低机位` | vibeshot-candid-photography；保留 5 组及全部条件 | 变成角色摄影或输出默认 10 组 |
| `$vsc 成年 COSER 扮演蒂法，长焦遮挡观察，n=10，只给提示词` | character-candid-photography | 因“蒂法”直接选择夏季泳装 |
| `$vsc 成年 COSER 扮演蒂法与爱丽丝，泳装、泳池泼水、朋友视角，一张照片` | summer-boyfriend-pov；识别实际图片交付 | 角色抓拍、多人变成多图、只给提示词就称完成 |
| `$vsc 普通成年人物在泳池边喝咖啡，穿日常衣服，给 3 组生活抓拍提示词` | vibeshot-candid-photography | 单凭泳池关键词改成泳装 |
| 上文已指定“两位成年朋友、泳装、同框、参考 A 锁定人物 A、参考 B 只参考构图、只要提示词”，本轮 `$vsc 继续` | summer-boyfriend-pov；传递已有约束 | 重问条件、交换参考职责、生图 |
| `$vsc 只写一对中国情侣在巴塞罗那旅行的 Vlog 方案和视频提示词` | virtual-couple-travel-vlog；只交付方案和提示词 | 要求先选输出目录才能写方案、直接提交视频生成 |
| `$vsc 把刚才 Codex 生成的这张图和原始提示词保存到 Eagle` | codex-image-to-eagle；使用真实文件和原始提示词 | 再生成一张、虚构导入成功 |
| `$vsc 为我的网站修复登录接口` | 说明没有匹配的 VSC 创作技能，可提供普通协助 | 强行选择图片或视频技能 |
| `$vsc 用 summer-boyfriend-pov 做十格角色设定页` | 说明显式选择与交付冲突，确认调整方向 | 静默切换技能或违背独立单图边界 |
| 夏季 POV 未安装，用户请求泳装朋友视角单张照片 | 说明 summer-boyfriend-pov 未安装 | 为了可用而强行用角色摄影替代 |
| 两处不同版本同名安装 | 先以宿主实际路径消除冲突，不能消除才询问 | 任意挑第一处 |
| `$vsc 先探索香水瓶风格，再生成图片，最后归档 Eagle` | 保留全部要求，识别当前明确的首步，先做风格提示词并说明后续未执行 | 自动串起全部技能、声称图片和归档也已完成 |

## 验收记录方式

记录模型、日期、输入、实际选择、实际交付范围和结果。只检查关键行为，不要求逐字匹配回答。对真实执行的提示词案例，检查是否加载了入选 SKILL.md、读取必要引用或运行所需脚本，并交付完整提示词。
